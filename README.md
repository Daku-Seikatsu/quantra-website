# Quantra marketing website

A responsive, static website for the Quantra desktop QA testing app.

## Preview
Open `index.html` in a browser. No build tools required.

## Sections
Hero, product dashboard, features, browser automation/Playwright export, Quality Records (requirements, defects, release versions, reusable test data), FAQ, and coming-soon download area.

## Publish
Upload the contents of this folder to GitHub Pages or Cloudflare Pages.

## Before public release
Replace the coming-soon download section only after a validated Windows installer is available. Confirm all advertised capabilities against the current app build.
